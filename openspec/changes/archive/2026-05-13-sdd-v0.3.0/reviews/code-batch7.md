## Minor Issues

### M1: sdd-ship 完成引导中"无后续操作"与渐进采用内容共存

**文件**: `skills/sdd-ship/SKILL.md` L86-88
**现状**:
```
变更已完成，无后续操作。
  当前使用阶段: [根据使用的 action 推断]
  下一阶段建议: [推荐可以开始使用的额外 action]
```
**问题**: "变更已完成，无后续操作。"与后续的渐进采用提示内容在语义上冲突。Spec 要求"不输出 ★○△ 推荐列表"，但渐进采用内容属于不同的信息类别（教育性而非操作性），保留是合理的。然而放在同一段落内可能误导为"有后续操作"。
**建议**: 将"变更已完成，无后续操作。"与渐进采用提示用空行分隔，或在渐进采用前加一句过渡："以下是长期使用建议，与当前变更无关："。
