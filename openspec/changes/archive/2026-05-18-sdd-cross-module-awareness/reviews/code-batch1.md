### [severity: minor] sdd-propose: "跳到步骤 2"的目标有歧义
- **文件:** `skills/sdd-propose/SKILL.md` 第 73、79 行
- **描述:** 步骤 1 的前置判断说"跳到步骤 2"，步骤 2 的 N<=1 分支也说"跳到步骤 2"。前者指后置逻辑的步骤 2（产物校验），后者在同一编号体系内容易误解为跳到本节的子步骤 2（扫描项目结构），造成两种"步骤 2"的歧义。
- **建议:** 将跳转目标改为明确描述，例如步骤 1 中改为"跳到步骤 4（用户确认）之后的后续逻辑"，或使用"跳过后续步骤，直接进入后置逻辑步骤 2（产物校验）"。另一个简单的做法是给后置逻辑的"产物校验"一个不同于 1-4 的标签，如"→ 后置步骤 2"。

### [severity: minor] sdd-ship: 延后项提取的模板路径使用了 schema 相对路径
