# Plan Review — Round 1

**审查对象:** plan.md
**日期:** 2026-06-15

## Round 1 Issues

### [major] TDD 验证方式过于表面化 — FIXED (Round 3)
- 所有验证使用 `grep -c` 检查关键词存在性，无法验证语义正确性
- 修复：增加结构化验证（`grep -A` 上下文匹配、`grep -n` 行号定位、`grep -Ec` 扩展正则）

### [major] RED 步骤前提假设可能不成立 — FIXED (Round 3)
- RED 步骤假设文件不包含目标关键词，可能误判
- 修复：每个 RED 步骤增加"前置确认"阶段，先读取文件验证当前状态

### [major] 批次三与批次一/二存在大量重复 — FIXED (Round 2)
- 批次三的验证步骤与实现批次的 GREEN 验证重复
- 修复：批次三重新定义为集成验证（测试套件、结构完整性、场景覆盖）

### [major] 章节编号逻辑错误 — FIXED (Round 3)
- Task 1.1 要求在 `### 2.` 之前添加 `### 3.`，导致编号混乱
- 修复：改为在 `### 2.` **之后**添加 `### 3.`

### [minor] Spec 场景覆盖不完整 — FIXED (Round 3)
- Task 1.4 未列出需覆盖的 spec 场景清单
- 修复：添加显式场景清单（自动修复成功/失败、手动修复完成/不完整）

### [minor] 粒度不一致 — FIXED (Round 2)
- Task 1.4 包含 4 种修复逻辑 + 汇总，粒度过粗
- 修复：拆分为 Task 1.4（自动修复+手动修复）和 Task 1.5（跳过+标记+汇总）

### [minor] 缺少"用户修改不完整"场景 — FIXED (Round 2)
- Task 1.4 未覆盖 spec 中的"用户修改不完整"场景
- 修复：在手动修复逻辑中添加"验证不完整 → 提示缺失项"

### [minor] grep 转义字符问题 — FIXED (Round 3)
- `\|` 在某些 shell 环境下不兼容
- 修复：统一使用 `grep -Ec` 和 `|` 语法

### [minor] 缺少依赖关系声明 — FIXED (Round 3)
- 批次一/二内任务存在依赖但未声明
- 修复：添加 `依赖: Task X.X` 标注和批次级顺序说明
